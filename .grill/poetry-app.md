# Grill: 诗词 App（月光白 · 仿宋 · 每日一首）
日期: 2026-07-26

## 意图
做一款真正让人想打开、想读诗的 Android App。核心体验是「每天打开随手滑一首，像翻日历一样自然」。不是大而全的诗词字典，而是一个有温度、有美感的日常陪伴工具。

## 约束
- 纯本地 App，不联网、不登录、无账号体系，仅限老板和对象用
- 默认仿宋 + 支持多种字体切换（含本地 ttf/otf 导入）
- 月光白配色基调，不碰红白（痛点：西窗烛的红白配色）
- 离线能用：至少已读/收藏的诗词离线可看
- 只用诗泉 API（远程）获取诗词数据，不额外找其他 API

## 关键决策
- **技术栈**: Kotlin + Jetpack Compose + Material3。原因：滑动过渡/渐变动效/字体实时切换需要声明式 UI 的动画能力。备选：传统 XML 布局（复杂度高，动效难做）
- **底部导航**: 每日 / 文库 / 发现 / 我的（4项）。备选拒绝：每日/分类/搜索/我的（太通用）；首页/分类/收藏/设置（搜索入口藏得太深）
- **每日推荐算法**: 时令优先 + 启动时间匹配 + 随机兜底。早上→晨诗，中午→闲适诗，晚上→夜诗。备选拒绝：纯随机（太冷门）、编辑精选（维护成本高）
- **配图策略**: 内置画库（精选 200-500 张国风图） + 哈希渐变色双轨。有图用图，没图用每首诗 SHA256 生成的唯一 HSL 渐变。备选拒绝：纯内置画库（包爆炸）、纯哈希渐变（缺惊喜感）
- **换一首逻辑**: 智能随机——默认随机，但如果当前诗被收藏或停留超 10 秒，偏同类风格/作者。备选拒绝：纯随机（无延续感）、同作者（太死板）
- **浏览模式**: 列表 + 网格双模可切换。备选拒绝：纯列表（不够精致）、三级目录（太重）
- **发现页模块**: 热门排行 + 随机一首 + 本周回顾（砍掉飞花令，因为太像游戏，和 App 整体调性不搭）
- **离线策略**: 缓存已读。收藏/浏览过的诗词自动存 Room，无网可看。备选拒绝：全在线（断网废了）、内置精选库（首次包太大）
- **首日体验**: 按启动时间匹配第一首诗，而不是纯随机，避免冷门生僻诗劝退

## 暴露的假设
- 假设诗泉 API 长期稳定可用，未考虑自建 fallback
- 假设老板和对象只在 Android 上使用，未考虑 iOS/平板
- 假设画库图片可以合法使用（国风公有领域作品）

## 未解决的问题
- 画库图片来源：需要确认具体从哪里收集（古画公版图源？AI 生成？）
- 热门排行的初始数据：App 刚装时没有用户行为数据，热门榜需要内置种子数据
- 深色模式「墨色夜读」的色值细节需要 UI 打磨

## 不做的范围
- ❌ 不做用户登录/账号/云同步
- ❌ 不做飞花令交互游戏
- ❌ 不做社区/评论/分享
- ❌ 不做 iOS 版
- ❌ 不可推广告/开屏/商业化
- ❌ 不用 XML 布局，全用 Compose
